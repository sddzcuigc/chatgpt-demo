# 设计蓝图

## 页面
单页：输入表单、门禁结果、最近记录。

## 组件
制品名称、来源、访问方式、HTTP 状态、有效期、构建耗时、权限要求、完整性校验、备用来源、探测证据、评分卡、检查项、保存和导出。

## 状态
1. 禁止进入构建：来源、权限或探测未验证。
2. 只能人工试取：可探索但不能自动化。
3. 可进入一次性构建：当前可用，但缺长期稳定性。
4. 允许进入自动构建：访问、寿命、完整性和备用来源均有证据。

## 数据流
用户输入 → 本地规则计算 → 评分与状态 → LocalStorage → Markdown 导出。

## 交互
载入 403 示例、实时重新计算、保存最近 20 条记录、导出单次结果。

## 响应式
>760px 双栏；≤760px 单栏。所有操作按钮可换行，390px 不出现横向滚动。

## 验收对照
- 403 示例必须被阻断。
- 状态 200、有效期≥2倍构建耗时、校验与备用来源齐全时放行。
- 刷新后保存记录仍存在。
- 导出 Markdown 包含全部关键字段。
- 无网络请求、无密钥。
