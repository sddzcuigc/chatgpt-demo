# 设计蓝图

## 页面
单页：故障输入区、诊断结果区、最近故障指纹区。

## 组件
项目名、阶段、状态、错误原文、上下文、根因、下一步动作、回滚点、复现步骤、证据完整度、诊断等级、历史记录和导出按钮。

## 状态
1. 黑盒故障：核心证据缺失。
2. 初步假设：可以排查但不能确认根因。
3. 最小诊断：可执行单一验证动作。
4. 可复用故障指纹：可复现、可回滚、可验证。

## 数据流
用户输入 → 本地规则评分 → 诊断状态 → LocalStorage → Markdown 导出。

## 响应式
大于 760px 双栏；小于等于 760px 单栏。
