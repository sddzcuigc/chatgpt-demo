# 产品规格

- 使用者：独立开发者、小团队、自动化工作流维护者。
- 决策者/付款者：项目负责人、交付团队、运维负责人。
- 不解决的损失：重复排查、错误归因、无效重试、部署停摆。
- 现有替代：Vercel 日志、Sentry、Datadog、人工故障记录。
- 通用 AI 可替代性：AI 能解释日志，但不能自动补齐缺失上下文、回滚点和真实复现证据。
- 差异：不是监控平台，而是把一次部署失败压缩成 5 分钟可执行诊断闭环。
- 商业模式：交付模板、团队工作坊、CI/Agent 门禁组件。
- 维护成本：低，纯前端规则；后续若接入日志平台，维护成本显著上升。
- 合规/IP 风险：低，但不得写入密钥、Cookie、内部域名和敏感日志。
- 真正壁垒：故障指纹库、根因命中率、修复动作有效率和跨平台兼容模板。
