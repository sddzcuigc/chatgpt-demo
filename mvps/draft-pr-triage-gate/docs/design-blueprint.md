# 设计蓝图

## 页面
单页：草稿清单、分诊结果、门禁规则。

## 组件
PR 标题、开放天数、验证证据、主题重叠、删除、新增、执行分诊、保存、导出、状态卡、结果列表。

## 状态
1. 无输入：阻断。
2. 超过 3 个建议保留：禁止新增。
3. 存在关闭/合并/暂停项：先清理再开发。
4. 全部满足门槛：允许继续。

## 交互
载入真实场景；编辑任意字段；本地计算；保存 LocalStorage；导出 Markdown。

## 数据流
手工或 GitHub 元数据 → 规则判断 → 行动建议 → 本地历史/导出。

## 响应式
820px 以下单栏；430px 以下按钮全宽、字段单列。

## 验收对照
- 5 个当前 Draft PR 可载入
- 高重叠 PR 输出“合并”
- 无验证输出“暂停”
- 7 天无验证输出“关闭”
- 建议保留超过 3 个时阻断新增
- LocalStorage 与 Markdown 导出可用
