# 设计蓝图

## 页面
单页工具：左侧为运行时契约输入，右侧为检查结论与历史记录。

## 组件
- 项目名称
- Vercel Project Node.js Version
- `package.json` 的 `engines.node`
- `.nvmrc`
- `.node-version`
- `vercel.json` 运行时声明
- 最近构建错误
- 人工接管步骤
- 检查按钮、示例按钮、保存按钮、Markdown 导出按钮
- 状态卡、逐项检查列表、最近记录

## 状态
1. 尚未检查：没有形成结论。
2. 禁止部署：仓库或 Project 仍声明 Node 18/20，继续部署会重复失败。
3. 只需修改 Vercel Project：仓库已兼容 24.x，但 Project 设置仍旧。
4. 可以部署：Project 和仓库配置都与 Node.js 24.x 一致，且最近日志不再出现旧版本错误。

## 交互
- 载入真实错误示例后立即显示阻断原因。
- 修改任一配置后重新检查。
- 保存最近 20 条检查记录到 LocalStorage。
- 导出 Markdown，供 PR、Notion 或交接记录使用。

## 数据流
用户输入 → 规范化版本字符串 → 检测旧版本与冲突 → 输出门禁状态 → LocalStorage/Markdown。

## 响应式规则
- 宽度大于 760px：输入与结果双栏。
- 宽度不超过 760px：单栏排列，按钮允许换行。
- 表单宽度 100%，避免 390px 横向溢出。
