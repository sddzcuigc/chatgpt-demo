# 设计蓝图

## 页面
单页：资源登记区、复用判断区、最近占用记录区。

## 组件
资源名称、资源类型、当前用途、空闲证据、租用截止日期、负责人、隔离方式、退出条件、禁止覆盖内容、判断卡、检查清单、保存与导出。

## 状态
1. 禁止复用：缺少空闲证据、隔离或退出机制。
2. 活跃资源不可占用：当前用途为活跃。
3. 可临时占用：主要条件具备，但仍有缺口。
4. 可安全复用：空闲证据、租期、负责人、隔离、退出和保护边界全部具备。

## 交互
输入实时计算；载入示例；保存到 LocalStorage；导出 JSON。

## 数据流
用户输入 → 本地规则判断 → 状态与缺口 → LocalStorage/JSON。

## 响应式
大于 760px 双栏；小于等于 760px 单栏。
