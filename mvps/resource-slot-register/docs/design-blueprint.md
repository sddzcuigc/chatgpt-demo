# 设计蓝图

## 页面
单页：租约登记区、判断区、到期队列区。

## 组件
资源名称、类型、状态、证据、到期日、负责人、隔离方式、退出条件、保护边界、续租理由、判断卡、到期队列、保存与导出。

## 状态
- 禁止复用：字段缺失或资源活跃。
- 租约有效：字段完整且未临近到期。
- 即将到期：剩余 2 天以内，优先清理或提交续租理由。
- 已过期：立即清理，重新审核后才可继续。

## 数据流
输入 → 本地规则计算剩余天数 → 状态判断 → LocalStorage 队列 → JSON 导出。
