# 产品规格

- 使用者：自动化负责人、独立开发者、内部工具维护者。
- 决策者：仓库或部署资源的实际负责人。
- 付款者：小团队负责人、咨询交付方或内部平台团队。
- 不解决的损失：覆盖活跃项目、旧部署被替换、资源归属不清、长期堆积试验目录。
- 现有替代：口头确认、README 备注、Issue、Notion 表格。
- 通用 AI 可替代性：AI 能生成清单，但不能替代真实提交、PR、域名和负责人核验。
- 商业模式：更适合作为 Agent 工作流治理模块或团队模板，不宜单独做大型 SaaS。
- 维护成本：低；主要成本是保持资源状态和租期真实。
- 合规/IP：不采集密钥和敏感数据；仅记录资源元信息。
- 真正壁垒：资源占用历史、冲突案例、自动发现空闲状态和过期清理能力。
