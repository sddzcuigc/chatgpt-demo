# Node 24 证据链看板设计蓝图

## 页面
单页静态看板，路径 `/node24-evidence/`。

## 组件
- 顶部标题与 MVP 标识
- 四项指标：证据总数、通过数、待验证数、完成度
- 证据表：检查点、版本、证据来源、状态
- 下一步卡片：独立验证命令、复制按钮、验收规则

## 状态
- 通过：版本与证据均可追溯
- 待验证：路径存在但尚未真实执行
- 阻断：发现非 24.x 或缺少日志

## 交互
点击“复制命令”复制 `npm run proof:node24:local`，按钮文字变为“已复制”。

## 数据流
静态证据数组 → 表格渲染 → 用户执行独立验证 → 后续由 evidence JSON 替换静态数据。

## 响应式
桌面端双栏；760px 以下改为单栏，表格转卡片式；390px 不产生横向溢出。

## 验收对照
- 根路径可访问
- 五项证据完整呈现
- 复制命令可用
- 390px 单栏
- 无后端、密钥或敏感数据
- 仓库、CI、Vercel 声明均为 Node 24.x
