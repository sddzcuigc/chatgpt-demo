# Node 24 Local Proof Runner 设计蓝图

## 页面
单页证据面板：输入说明、执行命令、四阶段流水线、结果卡、限制与人工接管。

## 组件
- 环境卡：基础镜像、Node 版本、锁文件状态
- 执行卡：一键命令与底层 Docker 命令
- 流水线：镜像构建 → 版本审计 → 项目构建 → 证据门
- 结果卡：PASS/FAIL、退出码、日志时间
- 限制卡：平台差异、网络依赖、原生模块

## 状态
1. 未运行：尚无本地证据。
2. 运行中：容器正在构建或执行。
3. 失败：任一阶段非零退出。
4. 通过：Node 24、审计、构建和证据门全部通过。

## 交互
复制一键命令；运行后按日志定位失败阶段；失败时展示对应修复步骤。

## 数据流
仓库源码 → Docker build → Node 24 容器 → npm install → audit → build → evidence gate → 退出码与日志。

## 响应式
桌面双栏展示流程与日志；390px 以下改为单栏，阶段卡纵向排列，命令允许横向滚动。
